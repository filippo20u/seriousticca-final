# Sito di Dr. Jeane Bosch

Sito statico in un solo file (`index.html`): nessun build, nessuna dipendenza.
I font arrivano da Google Fonts.

## Pubblicazione
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Da controllare prima di andare online
- Indirizzo email del form (cerca `mailto:` in `index.html`).
- Foto: sostituisci il riquadro "JB" (classe `portrait`) con un'immagine.
- Recapiti e testi: verificali con la titolare.
